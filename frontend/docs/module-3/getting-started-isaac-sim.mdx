# Getting Started with Isaac Sim

## Introduction to Isaac Sim

NVIDIA Isaac Sim is a powerful robotics simulation environment built on NVIDIA Omniverse. It provides photorealistic simulation capabilities for robotics development, testing, and training. Isaac Sim is essential for developing and validating robotics algorithms before deployment to real hardware.

## System Requirements

### Hardware Requirements
- **GPU**: NVIDIA GPU with compute capability 6.0 or higher (RTX 20xx/30xx series or better recommended)
- **VRAM**: Minimum 8GB (16GB+ recommended for complex scenes)
- **CPU**: Multi-core processor (Intel i7 or AMD Ryzen 7+)
- **RAM**: 32GB or more
- **Storage**: SSD with 20GB+ free space

### Software Requirements
- **OS**: Ubuntu 20.04 LTS or Windows 10/11
- **CUDA**: 11.8 or later
- **Isaac Sim**: Latest stable version (2023.1+)
- **ROS 2**: Humble Hawksbill

## Installation Process

### Installing Isaac Sim

1. **Download Isaac Sim**:
   - Visit the NVIDIA Developer website
   - Download Isaac Sim for your platform
   - Ensure you have an NVIDIA Developer account

2. **Install Prerequisites**:
   ```bash
   # Install NVIDIA drivers and CUDA
   sudo apt update
   sudo apt install nvidia-driver-535 nvidia-utils-535
   # Download and install CUDA 11.8+ from NVIDIA
   ```

3. **Install Isaac Sim**:
   - Extract the downloaded package
   - Run the installation script
   - Follow the on-screen instructions

4. **Verify Installation**:
   ```bash
   # Launch Isaac Sim
   cd /path/to/isaac_sim
   ./isaac-sim.sh
   ```

### Setting up ROS 2 Integration

To use Isaac Sim with ROS 2, you need to set up the Isaac ROS bridge:

```bash
# Install Isaac ROS packages
sudo apt update
sudo apt install ros-humble-isaac-ros-gems ros-humble-isaac-ros-common

# Source ROS 2 and Isaac Sim
source /opt/ros/humble/setup.bash
source /path/to/isaac_sim/setup.sh
```

## Launching Isaac Sim

### Basic Launch

```bash
# Launch Isaac Sim with default settings
./isaac-sim.sh

# Launch with specific scene
./isaac-sim.sh --scene /Isaac/Robots/Carter/carter_station.usd
```

### Launching with ROS 2 Bridge

```bash
# Launch Isaac Sim with ROS 2 bridge
./isaac-sim.sh --extpath /path/to/isaac_ros_bridge/extensions
```

## Basic Isaac Sim Interface

### Main Interface Components

1. **Viewport**: The main 3D view of the simulation
2. **Stage Panel**: Hierarchical view of the scene objects
3. **Property Panel**: Properties of selected objects
4. **Timeline**: Animation and simulation controls
5. **Console**: Log output and scripting interface

### Navigation Controls

- **Orbit**: Alt + Left mouse button
- **Pan**: Alt + Right mouse button
- **Zoom**: Alt + Middle mouse button or mouse wheel
- **Select**: Left mouse click

## Creating Your First Scene

### Basic Scene Setup

1. **Create a New Scene**:
   - Go to File → New Stage
   - Or use the "New Stage" button in the toolbar

2. **Add Ground Plane**:
   - Right-click in the Stage panel
   - Select Create → Ground Plane
   - Adjust size and properties as needed

3. **Add Lighting**:
   - Create → Distant Light for sun-like lighting
   - Create → Dome Light for environment lighting

4. **Add a Simple Robot**:
   - Create → Cube (for a simple robot representation)
   - Or import a robot model in USD format

### Importing Humanoid Models

Isaac Sim supports various robot models, including humanoid robots:

```python
# Python script to add a humanoid robot
import omni
from pxr import Gf, UsdGeom, UsdPhysics, PhysxSchema

# Create a humanoid robot
def create_humanoid_robot(stage, position):
    # Create robot root
    robot_path = "/World/HumanoidRobot"
    robot_prim = stage.DefinePrim(robot_path, "Xform")
    robot_prim.GetAttribute("xformOp:translate").Set(position)

    # Add body parts (simplified example)
    # Head
    head_path = f"{robot_path}/Head"
    head_prim = stage.DefinePrim(head_path, "Sphere")
    head_prim.GetAttribute("radius").Set(0.1)

    # Body
    body_path = f"{robot_path}/Body"
    body_prim = stage.DefinePrim(body_path, "Cylinder")
    body_prim.GetAttribute("radius").Set(0.15)
    body_prim.GetAttribute("height").Set(0.5)

    return robot_prim
```

## Setting up Scenes, Lighting, and Physics

### Scene Configuration

1. **Environment Setup**:
   - Add ground plane or terrain
   - Configure environment maps for realistic lighting
   - Set up atmospheric effects if needed

2. **Lighting Configuration**:
   - **Distant Light**: For sun-like directional lighting
   - **Dome Light**: For environment-based lighting
   - **Rect Light**: For specific area lighting
   - **Sphere Light**: For point light sources

3. **Physics Configuration**:
   - Enable physics on objects that need simulation
   - Set up collision shapes
   - Configure material properties (friction, restitution)

### Physics Properties

```python
# Configure physics properties for objects
def setup_physics_properties(prim_path):
    # Enable physics on the object
    physx_collision_api = PhysxSchema.PhysxCollisionAPI.Apply(prim_path)
    physx_collision_api.GetContactOffsetAttr().Set(0.001)
    physx_collision_api.GetRestOffsetAttr().Set(0)

    # Set up rigid body properties
    physx_rigid_api = PhysxSchema.PhysxRigidBodyAPI.Apply(prim_path)
    physx_rigid_api.GetSleepThresholdAttr().Set(0.005)
    physx_rigid_api.GetStabilizationThresholdAttr().Set(0.01)
```

## Isaac Sim Python API

Isaac Sim provides a comprehensive Python API for programmatic control:

```python
import omni
import carb
from omni.isaac.core import World
from omni.isaac.core.robots import Robot
from omni.isaac.core.utils.stage import add_reference_to_stage
from omni.isaac.core.utils.nucleus import get_assets_root_path

# Initialize Isaac Sim world
world = World(stage_units_in_meters=1.0)

# Add a robot to the world
assets_root_path = get_assets_root_path()
if assets_root_path is None:
    carb.log_error("Could not find Isaac Sim assets folder")

# Add a Carter robot as an example
carter_path = assets_root_path + "/Isaac/Robots/Carter/carter_navigation.usd"
add_reference_to_stage(carter_path, "/World/Carter")

# Reset the world to start simulation
world.reset()

# Run simulation steps
for i in range(100):
    world.step(render=True)
    if i % 10 == 0:
        print(f"Simulation step {i}")

# Clean up
world.clear()
```

## Best Practices for Isaac Sim

1. **Scene Optimization**:
   - Use appropriate polygon counts for meshes
   - Optimize materials and textures
   - Use level-of-detail (LOD) where appropriate

2. **Performance**:
   - Adjust physics substeps for stability vs performance
   - Use fixed timestep for consistent simulation
   - Monitor GPU and CPU usage

3. **Reproducibility**:
   - Save scenes as USD files for consistent results
   - Use fixed random seeds for deterministic behavior
   - Document simulation parameters

## Troubleshooting Common Issues

### GPU Issues
- Ensure proper NVIDIA drivers are installed
- Check CUDA version compatibility
- Verify GPU has sufficient VRAM

### Performance Issues
- Reduce scene complexity
- Adjust physics parameters
- Close unnecessary applications

### ROS 2 Bridge Issues
- Verify ROS 2 installation
- Check network configuration
- Ensure proper environment sourcing
