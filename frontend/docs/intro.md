# Physical AI & Humanoid Robotics

Welcome to the comprehensive textbook on Physical AI and Humanoid Robotics. This book is divided into four modules that will take you from the fundamentals of ROS 2 to building complete Vision-Language-Action (VLA) systems for humanoid robots.

## Module Overview

- **Module 1**: ROS 2 fundamentals - Learn about nodes, topics, services, and actions
- **Module 2**: Digital Twin technologies - Explore Gazebo physics and Unity rendering
- **Module 3**: AI-Robot Brain using NVIDIA Isaac - Work with Isaac Sim, VSLAM, and Nav2
- **Module 4**: Vision-Language-Action (VLA) systems - Build voice-controlled robots with LLM planning

## Getting Started

Start with Module 1 to learn the foundational concepts, or jump to any module that interests you. Each module includes hands-on projects and practical examples to reinforce your learning.
