# VLA System Quickstart Guide

This guide provides step-by-step instructions for setting up and validating the complete Vision-Language-Action (VLA) system, with special focus on Whisper and LLM integration compatibility.

## Prerequisites

Before starting, ensure you have:

- Python 3.10+ installed
- Node.js 18+ installed
- OpenAI API key with access to Whisper and GPT-4 models
- Qdrant Cloud account (or local instance)
- PostgreSQL database (or Neon Serverless)

## Installation

### 1. Clone the Repository

```bash
git clone <repository-url>
cd ai-native-book
```

### 2. Set Up Backend Services

```bash
# Navigate to backend directory
cd backend

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Set Up RAG Service

```bash
# Navigate to rag directory
cd rag

# Install dependencies
pip install -r requirements.txt
```

### 4. Set Up Frontend

```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install
```

### 5. Configure Environment Variables

Create a `.env` file in the root directory:

```env
# OpenAI Configuration
OPENAI_API_KEY=your_openai_api_key_here

# Qdrant Configuration
QDRANT_URL=https://your-cluster-url.qdrant.io
QDRANT_API_KEY=your_qdrant_api_key_here

# Database Configuration
DATABASE_URL=postgresql://username:password@ep-xxx.us-east-1.aws.neon.tech/dbname

# Logging Configuration
LOG_LEVEL=INFO

# RAG Configuration
TOP_K=5
EMBEDDING_MODEL=text-embedding-ada-002

# LLM Configuration
LLM_MODEL=gpt-4-turbo

# Whisper Configuration
WHISPER_MODEL=whisper-1
```

## Troubleshooting

### Common Issues

1. **API Key Issues**: Ensure your OpenAI API key is valid and has sufficient quota
2. **Qdrant Connection**: Verify Qdrant URL and API key are correct
3. **Database Connection**: Check DATABASE_URL format and credentials
4. **ROS2 Integration**: The simulated ROS2 integration works without actual ROS2 installation

### Verification Checklist

- [ ] Whisper API responds to transcription requests
- [ ] LLM generates valid action plans
- [ ] Vision service detects objects in images
- [ ] Action mapping converts plans to ROS2 actions
- [ ] RAG system retrieves relevant content
- [ ] Complete pipeline processes voice commands end-to-end
- [ ] Frontend displays documentation correctly
- [ ] All API endpoints return expected responses
