# Depth Camera Simulation

## Introduction to Depth Cameras in Robotics

Depth cameras provide crucial 3D spatial information that enables robots to understand their environment in three dimensions. Unlike traditional RGB cameras, depth cameras capture distance information for each pixel, enabling applications like 3D mapping, obstacle detection, and object recognition.

## Types of Depth Cameras

### RGB-D Cameras
- Provide both color (RGB) and depth information
- Common models: Microsoft Kinect, Intel RealSense
- Output topics: `/camera/rgb/image_raw`, `/camera/depth/image_raw`

### Stereo Cameras
- Use two cameras to compute depth through triangulation
- More robust in varying lighting conditions
- Require more computational resources

### Time-of-Flight (ToF) Cameras
- Measure depth by timing light pulses
- Fast and accurate but limited range
- Good for close-range applications

## Processing Depth Camera Data

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image, CameraInfo
from cv_bridge import CvBridge
import cv2
import numpy as np

class DepthCameraProcessor(Node):
    def __init__(self):
        super().__init__('depth_camera_processor')
        self.bridge = CvBridge()

        # Subscribers for RGB and depth images
        self.rgb_sub = self.create_subscription(
            Image,
            '/camera/rgb/image_raw',
            self.rgb_callback,
            10)

        self.depth_sub = self.create_subscription(
            Image,
            '/camera/depth/image_raw',
            self.depth_callback,
            10)

        # Publisher for processed data
        self.object_pub = self.create_publisher(
            Image,  # In practice, you'd use a custom message
            '/camera/processed_objects',
            10)

        self.depth_image = None
        self.rgb_image = None

    def rgb_callback(self, msg):
        try:
            self.rgb_image = self.bridge.imgmsg_to_cv2(msg, "bgr8")
            self.process_images()
        except Exception as e:
            self.get_logger().error(f'Error processing RGB image: {e}')

    def depth_callback(self, msg):
        try:
            # Depth image is usually in 16UC1 or 32FC1 format
            self.depth_image = self.bridge.imgmsg_to_cv2(msg, "32FC1")
            self.process_images()
        except Exception as e:
            self.get_logger().error(f'Error processing depth image: {e}')

    def process_images(self):
        if self.rgb_image is None or self.depth_image is None:
            return

        # Example: Find objects at specific depth ranges
        depth_mask = (self.depth_image > 0.5) & (self.depth_image < 2.0)  # 0.5m to 2m

        # Apply mask to RGB image to highlight objects at specific depth
        highlighted_image = self.rgb_image.copy()
        highlighted_image[~depth_mask] = [0, 0, 0]  # Black out areas outside depth range

        # Convert back to ROS message and publish
        try:
            processed_msg = self.bridge.cv2_to_imgmsg(highlighted_image, "bgr8")
            processed_msg.header.stamp = self.get_clock().now().to_msg()
            processed_msg.header.frame_id = "camera_link"
            self.object_pub.publish(processed_msg)
        except Exception as e:
            self.get_logger().error(f'Error publishing processed image: {e}')

    def get_depth_at_point(self, u, v):
        """Get depth value at pixel coordinates (u, v)"""
        if self.depth_image is not None and 0 <= u < self.depth_image.shape[1] and 0 <= v < self.depth_image.shape[0]:
            return self.depth_image[v, u]
        return None

    def convert_pixel_to_3d(self, u, v, depth):
        """Convert pixel coordinates + depth to 3D world coordinates"""
        # This requires camera intrinsic parameters
        # Simplified version - in practice, use camera_info topic
        fx = 525.0  # focal length x
        fy = 525.0  # focal length y
        cx = 319.5  # principal point x
        cy = 239.5  # principal point y

        x = (u - cx) * depth / fx
        y = (v - cy) * depth / fy
        z = depth

        return np.array([x, y, z])

def main(args=None):
    rclpy.init(args=args)
    depth_processor = DepthCameraProcessor()

    try:
        rclpy.spin(depth_processor)
    except KeyboardInterrupt:
        pass
    finally:
        depth_processor.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Unity Depth Camera Simulation

In Unity, you can simulate depth cameras using multiple techniques:

```csharp
using UnityEngine;
using System.Collections.Generic;

[RequireComponent(typeof(Camera))]
public class UnityDepthCamera : MonoBehaviour
{
    public Shader depthShader;
    private Camera depthCamera;
    private RenderTexture depthTexture;

    [Header("Depth Settings")]
    public float maxDepth = 10.0f;
    public int resolution = 640;

    void Start()
    {
        depthCamera = GetComponent<Camera>();

        // Create render texture for depth
        depthTexture = new RenderTexture(resolution, resolution, 24);
        depthTexture.format = RenderTextureFormat.RFloat; // Single channel float
        depthTexture.antiAliasing = 1;
        depthTexture.depth = 24;

        depthCamera.targetTexture = depthTexture;
        depthCamera.SetReplacementShader(depthShader, "RenderType");
    }

    void Update()
    {
        // The depth camera automatically renders each frame
        // The depth texture can be accessed via depthTexture
    }

    public float GetDepthAt(int x, int y)
    {
        // Read depth value at specific pixel (simplified - in practice, avoid ReadPixels for performance)
        RenderTexture.active = depthTexture;
        Texture2D depthTex = new Texture2D(depthTexture.width, depthTexture.height, TextureFormat.RFloat, false);
        depthTex.ReadPixels(new Rect(0, 0, depthTexture.width, depthTexture.height), 0, 0);
        depthTex.Apply();

        Color pixelColor = depthTex.GetPixel(x, y);
        float depthValue = pixelColor.r * maxDepth; // Assuming depth was normalized

        DestroyImmediate(depthTex);
        RenderTexture.active = null;

        return depthValue;
    }

    void OnRenderImage(RenderTexture source, RenderTexture destination)
    {
        // Custom post-processing for depth visualization
        Graphics.Blit(source, destination);
    }
}
```

## Generating Training Data from Depth Cameras

```python
import numpy as np
import cv2
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import os

class DepthDataExporter:
    def __init__(self, output_dir="depth_training_data"):
        self.output_dir = output_dir
        self.bridge = CvBridge()
        self.sample_count = 0

        # Create output directories
        os.makedirs(os.path.join(output_dir, "rgb"), exist_ok=True)
        os.makedirs(os.path.join(output_dir, "depth"), exist_ok=True)
        os.makedirs(os.path.join(output_dir, "annotations"), exist_ok=True)

    def export_training_sample(self, rgb_image, depth_image, annotation=None):
        """
        Export RGB and depth images as training data
        """
        # Save RGB image
        rgb_filename = os.path.join(self.output_dir, "rgb", f"rgb_{self.sample_count:06d}.png")
        cv2.imwrite(rgb_filename, rgb_image)

        # Save depth image (convert to 16-bit for better precision)
        depth_filename = os.path.join(self.output_dir, "depth", f"depth_{self.sample_count:06d}.png")
        # Scale depth to 16-bit range (0-65535) for PNG storage
        scaled_depth = np.clip(depth_image / 10.0 * 65535, 0, 65535).astype(np.uint16)
        cv2.imwrite(depth_filename, scaled_depth)

        # Save annotation if provided
        if annotation is not None:
            annotation_filename = os.path.join(self.output_dir, "annotations", f"annotation_{self.sample_count:06d}.json")
            import json
            with open(annotation_filename, 'w') as f:
                json.dump(annotation, f)

        self.sample_count += 1
        print(f"Exported training sample {self.sample_count}")

    def process_depth_for_ai(self, depth_image):
        """
        Process depth image for AI model input
        """
        # Normalize depth values to [0, 1] range
        normalized_depth = np.clip(depth_image / 10.0, 0, 1)  # Assuming max depth of 10m

        # Fill in invalid depth values (NaN, infinity) with max depth
        normalized_depth[~np.isfinite(normalized_depth)] = 1.0

        # Optionally, create additional features like depth gradients
        gradients_x = np.gradient(normalized_depth, axis=1)
        gradients_y = np.gradient(normalized_depth, axis=0)

        return {
            'depth': normalized_depth,
            'gradients_x': gradients_x,
            'gradients_y': gradients_y
        }

def create_depth_augmentation(depth_image):
    """
    Apply realistic depth camera noise and artifacts
    """
    # Add realistic noise (more noise at greater distances)
    noise_factor = 0.01 + 0.02 * depth_image  # More noise at greater distances
    noise = np.random.normal(0, noise_factor, depth_image.shape)
    noisy_depth = depth_image + noise

    # Add quantization effects
    noisy_depth = np.round(noisy_depth * 1000) / 1000  # Round to mm precision

    # Add missing data in far distances (typical of real depth cameras)
    mask = np.random.random(depth_image.shape) > (0.95 - 0.1 * depth_image / 10.0)
    noisy_depth[~mask] = 0  # Set to 0 for missing data

    return noisy_depth
```

## Depth Camera Applications in Robotics

### Obstacle Detection
- Identify objects in the robot's path
- Calculate safe navigation routes

### 3D Reconstruction
- Build 3D maps of the environment
- Create point clouds for spatial understanding

### Object Recognition
- Combine with RGB data for better object detection
- Measure object size and distance

### Human-Robot Interaction
- Detect and track humans in the environment
- Enable gesture recognition

## Best Practices for Depth Camera Simulation

1. **Realistic Noise Models**: Simulate the specific noise characteristics of your target hardware
2. **Performance Optimization**: Balance simulation quality with computational efficiency
3. **Validation**: Compare simulated depth data with real sensor data when possible
4. **Multiple Viewpoints**: Simulate multiple camera angles for comprehensive training data
5. **Diverse Scenarios**: Include various lighting conditions and environments

## Summary

Depth camera simulation is a powerful tool for robotics development, providing crucial 3D spatial information for navigation, mapping, and object recognition. Properly configured depth cameras in simulation environments enable the development and testing of sophisticated perception algorithms before deployment to real hardware, while also providing valuable training data for AI systems.
